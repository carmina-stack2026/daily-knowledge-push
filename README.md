# 📖 每日知识推送系统

每天自动推送一条**寓言 / 神话 / 名著 / 历史 / 习俗**故事到企业微信。

---

## 🚀 快速部署（5分钟）

### 第一步：创建企业微信机器人

1. 下载「企业微信」App，用手机号注册
2. 创建内部群（可以只有自己）
3. 点击群右上角 `···` → **群机器人** → **添加机器人**
4. 复制 Webhook 地址（格式：`https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx`）

### 第二步：Fork 本仓库

1. 点击本页面右上角的 **Fork** 按钮
2. 等待仓库复制到你的账号下

### 第三步：配置机器人密钥

1. 进入你 Fork 后的仓库
2. 点击顶部菜单 **Settings**
3. 左侧选择 **Secrets and variables** → **Actions**
4. 点击 **New repository secret**
   - Name: `WEBHOOK_URL`
   - Secret: 粘贴你第一步复制的机器人地址
5. 点击 **Add secret**

### 第四步：测试推送

1. 点击仓库顶部 **Actions** 菜单
2. 左侧选择 **每日知识推送**
3. 右侧点击 **Run workflow** → **Run workflow**
4. 等待 10 秒，查看手机上的**企业微信**，收到第一条推送！

### 第五步：完成

✅ 之后每天北京时间 **08:00** 自动推送，无需任何操作。

## 🔄 「看过换一条」功能

如果某条内容你已经看过，想跳过它：

1. 打开 `history.json`
2. 添加一条记录：
   ```json
   {
     "id": "fable_001",
     "title": "龟兔赛跑",
     "category": "fable",
     "date": "2026-08-23"
   }
   ```
3. 提交修改

下次推送时会自动跳过这条内容。

## 🛠️ 自定义配置

### 修改推送时间

编辑 `.github/workflows/daily-push.yml`：

```yaml
schedule:
  - cron: '0 0 * * *'   # UTC 00:00 = 北京时间 08:00
```

Cron 表达式参考：
- `0 22 * * *` = 北京时间 06:00
- `0 1 * * *` = 北京时间 09:00
- `0 12 * * *` = 北京时间 20:00

### 添加新内容

编辑 `content.json`，按以下格式添加：

```json
{
  "id": "custom_021",
  "category": "custom",
  "title": "新故事标题",
  "content": "故事正文...",
  "moral": "寓意/启示",
  "source": "来源",
  "tags": ["标签1", "标签2"]
}
```
